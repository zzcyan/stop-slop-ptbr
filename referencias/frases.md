# Frases para cortar

## Aberturas que enrolam

Tire estas frases de anúncio. Diga o conteúdo direto.

- "Vamos lá:"
- "O ponto é o seguinte:"
- "A questão é:"
- "O segredo é"
- "Aqui está o que [X]"
- "Veja bem:"
- "A verdade é que"
- "A verdade nua e crua é que"
- "A real é que"
- "Acontece que"
- "Vou ser direto:"
- "Vou ser sincero" / "Preciso ser honesto"
- "Vou repetir:"
- "Precisamos falar sobre"
- "Sabe o que é interessante?"
- "O problema é o seguinte"
- "É aí que entra [X]"
- "Antes de mais nada,"
- "Sem mais delongas,"

Qualquer "o ponto é", "a questão é" ou "o segredo é" antes da ideia é enrolação. Corte e diga a ideia.

## Muletas de ênfase

Não acrescentam sentido. Apague.

- "Ponto final." / "Ponto."
- "Simples assim."
- "Leia de novo."
- "Pense nisso."
- "Isso importa porque"
- "Não se engane:"
- "E é por isso que isso importa"
- "Isso muda tudo."
- "Fica a dica."

## Jargão corporativo

Troque por português comum.

| Evite | Use |
|-------|-----|
| Navegar (pelos desafios) | Lidar com, resolver |
| Mergulhar fundo / mergulho profundo | Analisar, análise |
| Destrinchar | Explicar, examinar |
| Abraçar (a mudança) | Aceitar, adotar |
| Cenário, panorama (atual) | Situação, mercado |
| Divisor de águas, virada de chave, game changer | Importante, decisivo |
| Alavancar, potencializar | Usar, aumentar |
| Robusto | Completo, confiável (ou diga o que ele aguenta) |
| Jornada (do cliente) | Caminho, etapas |
| Ecossistema | Conjunto, sistema |
| Destravar (valor, potencial) | Liberar, permitir |
| Dobrar a aposta | Insistir, reforçar |
| Dar um passo atrás | Repensar |
| Daqui para frente, seguindo em frente | A partir de agora, depois |
| Retomar o assunto depois | Voltar a, rever |
| Estar na mesma página | Combinar, concordar |
| Agregar valor | Diga qual valor |
| Endereçar (um problema) | Resolver, tratar |
| Realizar, efetuar, proceder com + substantivo ("realizar a análise", "efetuar o pagamento") | O verbo direto: analisar, pagar |

## Advérbios

Corte advérbio em -mente. Nada de suavizador, intensificador ou ressalva.

Os mais comuns:

- "realmente"
- "simplesmente"
- "literalmente"
- "genuinamente"
- "sinceramente" / "honestamente"
- "basicamente"
- "essencialmente"
- "fundamentalmente"
- "inerentemente"
- "inevitavelmente"
- "profundamente"
- "verdadeiramente"
- "extremamente"
- "absolutamente"
- "curiosamente"
- "notavelmente"
- "crucialmente"

Corte também estes enchimentos:

- "só" e "apenas" quando não limitam nada ("apenas um lembrete")
- "de fato", "na verdade", "na real"
- "No fundo," / "Em essência,"
- "Nos dias de hoje," / "No mundo atual," / "No cenário atual,"
- "Vale ressaltar que" / "Vale destacar que" / "Vale lembrar que"
- "É importante notar que" / "É importante destacar que"
- "No fim das contas,"
- "Quando se trata de"
- "Em um mundo onde"
- "A realidade é que"
- "Em suma," / "Em resumo," no fim de texto curto
- "Ou seja," repetido ao longo do texto

## Comentário sobre o próprio texto

Tire os apartes que falam do texto. Deixe o texto andar sem anunciar a própria estrutura.

- "Dica:"
- "Spoiler:" / "Plot twist:"
- "Você já sabe disso, mas"
- "Mas isso é assunto para outro post"
- "Não é defeito, é recurso"
- "Disfarçado de"
- "O restante deste texto explica..."
- "Vou te mostrar passo a passo..."
- "Nesta seção, vamos..."
- "Como veremos adiante..."
- "Quero explorar..."
- "Neste artigo, você vai descobrir..."

## Ênfase encenada

Intimidade falsa ou sinceridade fabricada:

- "vai se infiltrando"
- "eu prometo"
- "Existe, sim, eu prometo"
- "Confia em mim"
- "Acredite:"

## Dizer em vez de mostrar

Anunciar que algo é difícil ou importante em vez de mostrar:

- "Isso é difícil de verdade"
- "É assim que se parece uma liderança de verdade"
- "É assim que X funciona na prática"
- "o que importa de verdade"

## Declarações vagas

Frases que anunciam importância sem dizer qual é a coisa. Corte.

- "Os motivos são estruturais"
- "As implicações são significativas"
- "Esse é o problema mais profundo"
- "Há muito em jogo"
- "As consequências são reais"

Se a frase diz que algo é importante, profundo ou estrutural sem mostrar o quê, corte ou troque pela coisa em si.
